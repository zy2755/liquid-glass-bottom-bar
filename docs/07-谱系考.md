# 07 · 谱系考:"GitHub 上的液态玻璃都是 Kyant0 谱系吗?"

> 数据全部实测自 GitHub API(2026-11):仓库创建时间、`search/code` shader 指纹比对。
> 结论先行:**Android 原生生态基本是;Web / iOS / Flutter 各有独立谱系;
> 且 Kyant0 是 Android 端的传播枢纽,不是折射数学的源头。**

## 一、方法论

1. **时间线**:`GET /repos/{owner}/{repo}` 取 `created_at`,对照 WWDC25(2025-06-09)之后各平台第一波实现;
2. **指纹**:`search/code?q=circleMap+sdRoundedRect` —— `circleMap`(圆弧映射)+ `sdRoundedRect`
   (圆角矩形 SDF)是 Kyant0 版 lens shader 的特征函数名组合,独立重写的实现几乎不会撞名;
3. **局限**:代码搜索只索引默认分支;fork 不计入;创建时间 ≠ 功能上线时间
   (Cloudy 2022 年就存在,liquidGlass 是后来加的;miuix 同理)。所以下表日期是"下限"。

## 四、分生态结论

### ① Android 原生(Compose/View)—— **基本是,Kyant0 系是事实标准**

传播链(按时间):

```
WWDC25 (06-09)
  └─ Kyant0/AndroidLiquidGlass (06-18,AGSL + Compose backdrop 采样封装)
       ├─ compose-miuix-ui/miuix ── WeKit ── NPatch(→ 酷安同款 shader)
       ├─ QmDeve/AndroidLiquidGlassView(View 体系,同指纹)
       └─ 一批一线 App:酷安、Echo-Music、BiliPai、PhotonCamera、Convx、TV 启动器…
例外:skydoves/Cloudy 的 liquidGlass(独立重写,无指纹;数学仍属 SDF 折射家族)
另一条线:chrisbanes/haze —— 只模糊不折射,不算液态玻璃,但常被一起用
```

### ② Web —— **完全不是 Kyant0,两条独立谱系**

- **shuding 系**(SVG `feDisplacementMap` 位移贴图,零依赖):shuding/liquid-glass →
  rdev/liquid-glass-react、xiaofangstudio/liquid-glass-web、KVideo 等;本仓库 web/ 演示即此路线;
- **WebGL/WebGPU 真折射系**:lucasromerodb(最早)、naughtyduk/liquidGL(1057★)、
  iyinchao/liquid-glass-studio(822★)、ybouane、Glass-HQ —— 各自独立实现,更物理正确。
- AGSL 是 Skia 方言,浏览器跑不了,所以 Kyant0 的 shader 在 web 上无人直接使用。

### ③ iOS —— **谱系问题不存在**

iOS 26 有系统 API(`glassEffectIOS()` / `UIGlassContainerEffect` / 自带玻璃的 UITabBar):
callstack/liquid-glass(RN)、expo-glass-effect、腾讯 Kuikly 全是原生封装,不写 shader。
(本仓库 docs/06 第三节。)

### ④ Flutter —— **独立 GLSL 谱系**

whynotmake-it/flutter_liquid_glass(WWDC 后 4 天,比 Kyant0 还早)用自己的
`assets/shaders/{sdf.glsl, material_sdf.glsl, fake_glass_*.frag}`,GLSL 而非 AGSL,
数学同家族、代码不同源;sdegenaar/liquid_glass_widgets 是另一套独立实现。

## 五、修正后的表述

| 常见说法 | 修正 |
|---|---|
| "GitHub 液态玻璃基本都是 Kyant0 谱系" | 仅 **Android 原生生态**成立;Web/iOS/Flutter 各有独立谱系 |
| "Kyant0 发明了这个折射算法" | SDF 位移折射是图形学通用数学;WWDC25 后一周内各平台**并行独立复刻**(Web 6/9、Flutter 6/13、Android 6/18) |
| "Kyant0 的贡献是什么" | **AGSL + Compose backdrop 采样的工程化封装与 API 设计**,以及这份实现在中文 Android 圈的高传播(miuix→WeKit→NPatch→酷安链) |
| "酷安自己写的 shader 很厉害" | shader 与开源谱系逐字一致;真正的工程量在采样管线/能力协商/交互状态机(docs/06) |

> 实操建议不变:Android 上直接用 Kyant0 backdrop(或本仓库收录的 miuix 系实现),
> 不必重复造 shader;Web 用 shuding 系;iOS 用系统 API;Flutter 用 GLSL 系。
> 需要跨端统一观感时,记住各谱系数学同源,参数(docs/04)可以互相翻译。
