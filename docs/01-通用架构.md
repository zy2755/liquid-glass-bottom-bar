# 01 · 通用架构:底栏液态玻璃的分层模型与可复用结论

> 来源:NPatch(生产级 Compose)、xiaofangstudio/liquid-glass-web(Web)、Kyant0/AndroidLiquidGlass(Compose 库)
> 三者在"应该怎么分层"上完全一致 —— 这就是可复用的架构结论。

## 一、五层管线(平台无关)

```
┌ 5. 表面处理    白/黑 tint、顶部镜面高光、内阴影、描边、按压变色
├ 4. 边缘折射    圆角矩形 SDF 高度场 → 沿法线位移采样 → 边缘"液态"弯曲
│               (可选:RGB 多次采样 → 色散 chromatic aberration)
├ 3. 磨砂模糊    blur + vibrancy(提饱和),让透过的内容"鲜艳而模糊"
├ 2. 背景采样    把玻璃背后的内容离屏复制一份,作为折射/模糊的输入
└ 1. 底层内容    页面内容 + 壁纸(必须延伸到玻璃之下!)
```

**顺序敏感**:效果链必须 `提饱和 → 模糊 → 折射`(Android `effects{}` DSL 按书写顺序执行);
先折射后模糊会把折射纹理糊掉,先模糊后提饱和会让模糊块发灰。

**为什么中心平、边缘弯**:SDF 距离场里 `-sd >= refractionHeight` 的区域(离边缘远)
直接原样采样(`return content.eval(coord)`),只有边缘一圈按
`circleMap(1.0 - -sd/height) * amount` 位移 —— 这就是 iOS 26 "玻璃中心平坦、边缘强烈弯曲"的全部秘密。

## 二、底栏特有处理(与普通玻璃按钮的差别)

### 1. 悬浮胶囊布局
- 全圆角(pill):`RoundedCornerShape(50%)` / `CircleShape`,高度 56~64dp;
- 底部留白:`12dp + WindowInsets.navigationBars`,左右 12~20dp,玻璃**不贴边**;
- 面板要投影:`dropShadow(pillShape, radius=10dp, alpha 亮0.1/暗0.2)`。

### 2. 内容必须垫到玻璃下面(最常见翻车点)
NPatch 源码注释(血泪经验):

> "Floating glass must sample page content behind itself. Applying Scaffold's
> bottom padding here clips the recorded backdrop above the navigation bar."

即:**不能**给滚动内容加 `bottom = 底栏高度` 的 padding —— 采样层会在玻璃上缘被裁掉,
玻璃折射/模糊到的是空白。正确做法:

```kotlin
// ❌ 错误:Scaffold 把 bottom padding 传给内容
Scaffold(bottomBar = { GlassBar() }) { padding -> Content(Modifier.padding(padding)) }

// ✅ 正确:内容铺满全屏参与采样;自己发一个"底栏高度+呼吸"的 padding 给列表尾部
Content(Modifier.fillMaxSize().layerBackdrop(backdrop))   // 全屏采样
LazyColumn(contentPadding = PaddingValues(bottom = bottomBarHeight + 20.dp + navBarInset))
```

### 3. backdrop 先填底色
```kotlin
val backdrop = rememberLayerBackdrop {
    drawRect(surfaceColor)   // ← 防止玻璃采样到透明像素(发黑/闪烁)
    drawContent()
}
```

### 4. 指示器三层结构(iOS 26 聚焦效果的核心)
NPatch `FloatingGlassBottomBar` 的结构,可整体照搬:

```
Box(宽=IntrinsicSize.Min)
├─ Row ①玻璃面板        drawBackdrop(全局backdrop): vibrancy→blur(4dp)→lens(24,24)
│                       onDrawSurface: tint(0.4 alpha);pressProgress→面板微膨胀
├─ Row ②tab内容副本     alpha(0f) 不可见,但 layerBackdrop(tabsBackdrop) 登记进第二采样
│                       ← 让"文字/图标"本身成为指示器的折射源
└─ Box ③指示胶囊        drawBackdrop(CombinedBackdrop(全局, tabsBackdrop))
                        lens(10dp·p, 14dp·p, depthEffect, chromaticAberration=0.5)
                        + innerShadow(8dp·p, black 15%) ← 按压下陷感
```

要点:**指示胶囊折射的是"全局背景 + 被选中 tab 的文字内容"**,所以滑动时能看到
文字在玻璃里被"揉"变形 —— 这是 iOS 26 Liquid Glass tab bar 的标志性观感。
`CombinedBackdrop` 实现极简:先画第一个 backdrop,再画第二个(见 `compose-miuix/liquid/CombinedBackdrop.kt`)。

### 5. 交互动效(参数见 04 速查表)
- **拖拽跟手**:指示器用阻尼动画随手指在 tab 间滑动(不只支持点击);
- **橡皮筋**:面板整体 `translationX = 4dp · sign · EaseOut(|fraction|)`;
- **速度挤压**(体积守恒):`scaleX /= 1 - (v·0.75).coerceIn(-0.2, 0.2)`,`scaleY *= 1 - (v·0.25)…`;
- **按压联动**(p = pressProgress 0→1):
  - 指示器折射加强:`refractionHeight = 10dp·p`,`refractionAmount = 14dp·p`
  - 下陷:`innerShadow(8dp·p, black 15%)`,亮色主题表面压黑 `10%→3%`
  - tab 图标放大 `1→1.2`,面板膨胀 `+16dp/width`
- **动态光源**:用加速度计(`DeviceTilt`)旋转镜面高光的位置向量,设备倾斜时高光"流动";
  双光源:主光在上方 `(0.5, -0.3)`,副光在下方 `(0.5, 0.8)`,强度 1 : 0.4。

### 6. 可读性兜底
玻璃再好看,tab 文字对比度是硬指标:
- 玻璃表面至少叠一层 `tint`(`white 0.08~0.4` 随模糊强度);
- 未选中项 alpha 0.6,选中项用主题色或纯白;
- 深色模式把 tint 换成黑色系(`black 0.1` 面 + 白高光),别复用亮色参数。

## 三、什么样的"软件"适合哪套方案

| 场景 | 推荐 | 理由 |
|---|---|---|
| Compose 新项目,要快速对齐 iOS 26 观感 | Kyant0 backdrop(教学级配方) | Maven 一行依赖,`lens()` 开箱即用 |
| 追求生产级细节(跟手拖拽/重力光/降级) | NPatch 的 FloatingGlassBottomBar | 已在真实应用验证,GPL-3.0 需合规 |
| Web / Electron / 混合开发壳 | liquid-glass-web 技术路线 | 零依赖,单文件;仅 Chromium |
| 老 View 体系 / Flutter / RN | 见调研报告 reference/调研报告 | 各生态库对比表 |
