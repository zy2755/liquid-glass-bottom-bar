# 04 · 参数速查表(跨平台对照)

> 全部来自三个来源的实际代码,可直接当调参起点。
> 符号:`p` = 按压进度(0→1),`v` = 归一化拖拽速度。

## 1. 玻璃面板(底栏本体)

> ⚠️ **观感取舍提醒**:`lens(refractionHeight)` 决定"边缘弯曲带"的厚度 ——
> NPatch 的 `24dp`(64dp 高的面板)意味着超过一半高度都在弯曲带里,**中心平坦区只剩 16dp**,
> 背景在文字背后扭曲感明显;Kyant0 demo 的 `16dp`(≈1/4 高)更接近 iOS 26
> "大平中心 + 薄边缘圈"的观感。**带文字的底栏建议 12~16dp 起步**,24dp 适合按钮/透镜类元素。

| 参数 | Android·NPatch | Android·Kyant0 demo | Web·liquid-glass-web |
|---|---|---|---|
| 高度 | 64dp(内容区 56dp + padding 4dp) | 64dp | 64px 左右 |
| 圆角 | 全圆(pill) | `RoundedCornerShape(32dp)` | pill,SDF 内缩 2~6px |
| 边距 | 左右 12dp,底 `12dp+navInset` | 左右 20dp,底 20dp | 左右 16px,底 `12px+safe-area` |
| 提饱和 | `vibrancy()` = saturation **1.5** | `vibrancy()` | `saturate(1.1)` |
| 模糊 | **4dp**(`liquidGlassBlurRadius`) | **4dp** | **0.25px** + `contrast(1.2) brightness(1.05)` |
| 折射 | `lens(h=24dp, amt=24dp)` ⚠️见上 | `lens(16dp, 32dp, depth, CA)` | SDF 内缩(0.3,0.2,r0.6) 阈值 −0.15 |
| 色散 | 面板无;指示器 0.5 | `chromaticAberration = true` | 无(单贴图) |
| 表面 tint | surface 色 **0.4** alpha(透明模式 0) | white **0.22** | `rgba(255,255,255,0.08)` |
| 投影 | `dropShadow r=10dp,α 亮0.1/暗0.2` | 无 | `0 4px 8px rgba(0,0,0,.25)` |
| 内阴影 | 无(指示器才有) | 无 | `0 -10px 25px inset rgba(0,0,0,.15)` |
| 降级 | Blur:blur **25dp** + tint **0.65** | API 31/32 自动降级 | Firefox:`blur(20px)` 毛玻璃 |

## 2. 选中指示器(NPatch 三层结构)

| 参数 | 值 |
|---|---|
| 尺寸 | `56dp × tabWidth`,全圆 |
| 折射(常态) | `lens(h=10dp·p, amt=14dp·p, depthEffect=true, chromaticAberration=0.5)` |
| 折射源 | `CombinedBackdrop(全局背景, tab内容副本)` ← 关键 |
| 高光 | BloomStroke 双光源:主光 `(0.5,−0.3,−0.05)` 强度1,副光 `(0.5,0.8,−0.5)` 强度0.4;`alpha = p` |
| 下陷 | `innerShadow(radius=8dp·p, black 15%, alpha=p)` |
| 表面 | 亮:`black 10%·(1−p)` → `black 3%·p`;暗:`white 10%·(1−p)` |
| tab 图标缩放 | `lerp(1f, 1.2f, p)` |
| 面板膨胀 | `lerp(1f, 1f + 16dp/width, p)` |

## 3. 拖拽 / 回弹

| 参数 | 值 |
|---|---|
| 指示器跟手 | DampedDragAnimation,target 连续跟随手指 |
| 面板橡皮筋 | `4dp · sign(f) · EaseOut(|f|)`,f = 拖动距离/总宽 |
| 松手回弹 | `spring(1f, 300f, 0.5f)` |
| 速度挤压 | `scaleX /= 1 − (0.75v)` clamp ±0.2;`scaleY *= 1 − 0.25v` clamp ±0.2 |
| Web 回弹 | 500ms,`springEase(t)=1−e^(−5t)·cos(9t)` |
| Web 按压 | `scale(1.05, 0.93)`,位移阈值 ÷1.3 重建贴图 |

## 4. Web 折射引擎(位移贴图)

| 参数 | 值 |
|---|---|
| 贴图尺寸 | 128~256px,随元素 resize/DPR 重建 |
| SDF | `roundedRectSDF(ix, iy, 0.3, 0.2, 0.6)`(**必须内缩**) |
| 强度 | `smoothStep(0.8, 0, d − 0.15)` → 再 `smoothStep(0,1,·)` |
| 归一化 | `maxScale = max(|raw|) · 0.5`(折半是原版手感) |
| 贴图像素 | `raw/maxScale + 0.5` ×255,R→x,G→y |
| feDisplacementMap | `scale = maxScale / devicePixelRatio` |
| 滤镜链 | `url(#f) blur(0.25px) contrast(1.2) brightness(1.05) saturate(1.1)` |

## 5. 光效扩展(liquid-glass-web,适合悬浮按钮/底栏活动光)

| 参数 | 值 |
|---|---|
| 体积光包络 | 按钮轮廓 2.6 倍椭圆(非点光源);外扩14% + blur 22px |
| 体积光寿命 | 1400ms,expo-out `cubic-bezier(0.16,1,0.3,1)` |
| 光束自转 | 6s/圈,淡出期旋转 80°;conic-gradient + screen 混合 |
| 光照互通 | radial-gradient + soft-light,距离线性衰减(700~900px) |
| 拖拽局部鼓包 | transform-origin 反侧偏移 30%,`k=min(0.14, dist/900)` |
| 拖拽拉伸上限 | 16%,体积守恒 `scale(1+k, 1−k·0.45)` |
| 速度平滑 | `vx = vx·0.7 + (Δx/dt)·16·0.3` |
| 滑行摩擦 | 0.94/帧,停后补 500ms 余晃 |
| 运动发光 | `glow=min(0.85, speed/26)`;阴影 `18+2.2·speed px`,α `0.12+glow·0.5` |
| 重力旋转光 | NPatch:加速度计单位向量 → 高光位置 `(0.5+lx, 0.7+ly)`,面板转 −45°/指示器 +90° |

## 6. 阈值/门槛

| 项 | 值 |
|---|---|
| Android 完整折射 | API **33+**(AGSL RuntimeShader) |
| Android 磨砂 | API **31+**(RenderEffect) |
| NPatch 开关 | `useFloatingGlassBottomBar` + `useFloatingGlassBottomBarBlur`(后者要求 SDK≥33) |
| Web 完整折射 | Chromium;Firefox/Safari 降级 blur |
| 重力光 API 门槛 | `InteractiveHighlight` 要求 API 33+ |
