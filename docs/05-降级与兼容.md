# 05 · 降级与兼容策略

## Android 能力分级

| API 级别 | 能力 | 底栏形态 |
|---|---|---|
| **33+**(Android 13) | AGSL `RuntimeShader`:真折射 + 色散 + 深度 | LiquidGlass 全效果(vibrancy→blur→lens) |
| **31–32**(Android 12/12L) | `RenderEffect` 模糊、Window Blur | Blur 模式:blur(25dp) + 65% tint,无折射 |
| **< 31** | 无系统模糊 | None:不透明底色 pill + 高光渐变模拟 |

NPatch 的落法(可直接抄):

```kotlin
// 能力判定
fun isFloatingGlassBottomBarBlurSupported() = Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU  // 33+

// 模式判定
val effectiveMode = if (backdrop == null && mode != None) None else mode
val isGlassTransparent = isLiquidGlass && liquidGlassBlurRadius <= 0.dp

// shader 内部兜底(liquid/Lens.kt)
if (!isRuntimeShaderSupported()) return          // 静默跳过,链上只剩 blur
if (refractionHeight <= 0f || refractionAmount <= 0f) return
```

要点:
- **降级不是砍功能,是换形态**:Blur 模式把模糊加大到 25dp、tint 提到 0.65,保证可读性;
- `lens()` 自己 `return` 即可 —— 效果链 DSL 里静默跳过,外层不用写 if-else;
- `InteractiveHighlight`(按压高光)单独判 API 33;
- 无 backdrop(比如页面没登记采样)→ 强制 None,别渲染"采到空气"的玻璃。

## Web 兼容

| 环境 | 策略 |
|---|---|
| Chromium 系 | 完整位移贴图折射 |
| Firefox / Safari | `backdrop-filter: url(#svg)` 不支持 → CSS 检测后加 `.fallback` 类:`blur(20px)` + 实底 rgba(255,255,255,.55) |
| 低端机 | `prefers-reduced-motion` 关闭果冻动画;贴图重建节流 |

```css
@supports not (backdrop-filter: url(#f)) {
  .glass-bar { background: rgba(255,255,255,.55); backdrop-filter: blur(20px); }
}
```

## 可读性与无障碍(所有平台必做)

1. **对比度**:tab 文字与玻璃面 ≥ WCAG AA(4.5:1)。玻璃 tint 不是可选项 ——
   NPatch 0.4、demo 0.22、web 0.08 都叠在足够强的 blur 之上;
2. **选中态双通道**:颜色 + 字重/图标切换(不要只靠颜色),NPatch 用
   `SemiBold + selectedIcon` 双通道;
3. **语义**:tab 要有 `Role.Tab` + `selected` + `onClick` 语义(NPatch 还处理了
   键盘 Enter/Space 激活与 focusable),Web 用 `<nav role="navigation"> + <button aria-selected>`;
4. **动效尊重**:`prefers-reduced-motion` / 系统关闭动画时长时,跳过果冻与挤压动画,
   直接到位;
5. **触达**:`touch-action`、44px 最小命中区、长按行为可关(`onTabLongPress` 返回 false)。

## 性能清单

- backdrop 采样层有代价:只在**需要玻璃的页面**登记 `layerBackdrop`,页面销毁即释放;
- `RuntimeShader` uniform 每帧更新要节制(按压进度用 `Animatable`,别每帧 setState);
- NPatch:内阴影/高光的 layer 复用(`shouldAutoInvalidate = false`,手动画);
- Web:贴图只在 resize/DPR/按压阈值变化时重建;滤镜链顺序 `url()` 放最前,后面只挂 1 个 blur;
- GPU 掉帧时第一刀砍**色散**(7 次采样 → 0),第二刀砍**折射**,最后才砍模糊半径。
